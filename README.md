# 冰島・倫敦旅行小冊

行動優先的旅行手冊。行程、三餐、住宿、準備清單與提醒整合在同一個網站，透過 Google Apps Script 與共用試算表同步。

## 介面與操作

- 手機日期列固定在底部，支援左右滑動、選中日期定位與安全區域留白。
- 切換日期直接定位到當天內容；旅程期間提供「回到今天」。
- 四段文字大小、深色模式、鍵盤日期切換及分頁操作。
- 行程列向左滑動或點「⋯」顯示編輯與刪除；刪除需再按一次確認。按住約兩秒後移動可拖曳排序。
- 更動沿用本機儲存、待上傳佇列與共用試算表同步流程。
- 更新提示使用半透明毛玻璃樣式，手機行程頁放在日期列上方，其他分頁放在畫面底部。

## 圖像與地圖

- 封面與十二天各自的主題插畫由內建 image_gen 生成，使用 WebP 儲存；提示詞見 [素材紀錄](assets/IMAGE-NOTES.md)。插畫為裝飾用途，不是景點實拍或路線圖。
- 分頁、餐食、住宿與日期卡使用原生 SVG 圖示。
- 目前行程中十九個不同的地圖位置都支援原地展開 Google Maps，保留原始外開導航連結。包含住宿、Bónus、取車機場、集合點、停車場、餐廳和景點。
- 地圖短網址已核對位置，使用 Google Maps 分享面板取得的嵌入資料，並調整為適合手機閱讀的街道視角。地圖第一次展開時才建立 iframe；離線時保留地名與地址，連線恢復後載入。
- 新增其他地圖短網址時，需在 `MAP_PREVIEWS` 補上對應的已核對嵌入資料；Google 官方 `/maps/embed?pb=...` 網址可直接使用。不能直接把短網址當作 iframe 來源。

## 本機預覽

在專案資料夾執行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

開啟 http://127.0.0.1:8765/ 。實際行程沿用 `config.js` 的 Apps Script 連線與既有通關密語。通關密語未寫在原始碼中，輸入後會保存在該瀏覽器的 localStorage。

## 離線與更新

應用程式、圖示與插畫都加入 Service Worker 快取，版本為 v11。Google 地圖仍需網路。既有用戶可透過「小冊有新版本」提示套用更新。

## 驗證範圍

已用隔離示範資料及 Chrome 檢查 320px、390px、1440px 版面、大字模式、深色模式、日期及分頁切換、觸控左滑、編輯儲存、刪除確認、拖曳排序與更新提示定位。JS 語法、manifest JSON 與 Git 空白檢查通過。

已逐天讀取實際行程畫面，核對十九個不同地圖連結皆有小地圖入口，並實際驗證住宿與集合點地圖載入、離線提示及恢復連線。未修改共用行程資料；沒有使用實際密語測試試算表寫入。iPhone 安全區域以 CSS env() 適配，尚未以實機驗證。
